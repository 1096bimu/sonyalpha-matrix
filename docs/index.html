Built-in color study

Tone curve · slope

Five slope controls at 0%, 25%, 50%, 75%, and 100%.

Bars set relative slope weights (0.05–3.00), normalized together to keep (0,0) and (1,1) fixed. Numbers above the bars show the resulting actual derivatives, always greater than zero. One shared curve for all RGB channels.

How the geometry works

Four degrees of freedom in projection; two in depth. Larger, brighter handles are nearer. The solid triangle joins RGB; the dashed triangle joins CMY. Tilt changes the matrix’s depth component, not the viewing camera.

Full geometric control. Neutral colors stay neutral. Arrow keys also move a focused vertex.

From this studio to your camera

Export the look, copy it to /MATRIX at the SD-card root, and reopen Matrix Test to select it. The camera applies the look during preview and JPEG capture; RAW sensor data stays unchanged. See the Sony Alpha Matrix project for installation and camera compatibility.

Independent community tool. Not affiliated with Sony. Intended for compatible PlayMemories Camera Apps bodies.

Preview & export

Browser preview uses tone → matrix and is an approximation of camera rendering. Images remain in your browser. The exported file keeps the tone curve and matrix as separate components.

Binary file format

Exactly 4,136 bytes: version 1, then 1,024 shared RGB tone samples, then 9 row-major matrix coefficients. All signed 32-bit, big-endian integers, with no padding.
